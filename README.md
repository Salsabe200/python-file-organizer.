# 📁 Python File Organizer

A simple and efficient Python automation tool that automatically scans any given folder (like `Downloads`) and categorizes files into separate subdirectories based on their file formats/extensions.

---

## 🚀 Features
- **Automatic Folder Creation:** Creates new folders for distinct file extensions (e.g., `pdf`, `png`, `zip`) if they don't already exist.
- **Safe File Sorting:** Moves files neatly without modifying their contents.
- **Directory Protection:** Automatically ignores existing directories to prevent execution errors.

---

## 🛠️ Built With
- **Python 3**
- Native Modules: `os`, `shutil`

---

1. Clone this repository or download `organizer.py`.
